## Key Features

- 🟢 Fully responsive, clean UI with a masonry card-style layout
- 🟢 Download any image directly from the feed
- 🟢 Google authentication for login/logout
- 🟢 Session persistence via local storage
- 🟢 Sanity-powered backend with a full CMS/admin panel
- 🟢 Complete CRUD operations managed through Sanity
- 🟢 Dynamic search, save, and comment functionality

## Tech Stack

| Technology | Purpose |
|---|---|
| **React** | Core frontend framework — powers the entire UI |
| **Tailwind CSS** | Utility-first styling |
| **react-masonry-css** | Masonry-style image grid layout |
| **react-icons** | Icon set used throughout the UI |
| **React Router** | Client-side navigation between views |
| **react-google-login** | Google OAuth authentication |
| **Sanity** | Headless CMS for backend data + admin panel |
